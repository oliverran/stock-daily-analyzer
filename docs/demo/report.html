如何阅读这个演示

数据是 DEMO_A、DEMO_B、DEMO_C 的固定价格公式，调用项目的 DailyBacktester，包含示例佣金、滑点和交易约束。它不验证行情接口、新闻或 LLM 服务。

Weekdays only; not an exchange trading calendar. 使用普通工作日，并非交易所日历。交易约束是简化示例，不应用于推断实盘表现。
